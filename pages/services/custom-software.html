Services

Custom software development

Software and automation built around how your team works, including test data and workflow tools for teams that build and test hardware.

What I build

  • R&D and manufacturing test software: data acquisition and test station software.
  • Database setup and analysis tools, so test data is stored well and easy to search and report on.
  • Dashboards and reports that turn raw data into answers your team can act on.
  • Workflow and automation tools that take repeat work off your team's plate.
  • Desktop and web applications, and AI agents that plug into them.

A sample: a test results dashboard

To show what this can look like, I built a test results dashboard for a made-up factory, with made-up data. It shows first-pass yield by day, the most common failures and every failed unit, with filters, search and a CSV export. A real one would read from your own test stations or database.

Who it's for

Teams that build and test hardware, and any business with a process that has outgrown spreadsheets, copy and paste, or a tool nobody wants to touch anymore.

Tools I work with

C#, .NET, SQL Server, PostgreSQL, LabVIEW, NI-DAQmx, NI-VISA and JavaScript, plus AI tools to get from idea to working software fast.
