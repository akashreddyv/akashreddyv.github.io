How this site is built

reachakash.com is my own website: fast pages with no framework, an admin page I can use from my phone, and forms that reach my inbox without a server to look after.

Fast, simple pages

  • Every page is plain HTML, CSS and a little JavaScript, generated from one shared template by a small build script. There's no framework and nothing to load before the page shows.
  • The font, icons and images are served from the site itself, with a smaller home photo for phones.
  • Pages can be read with JavaScript turned off, there are light and dark themes, and the reduced-motion setting is respected.

Updating it from a phone

  • An admin page, built on the open-source Decap CMS, lets me add photos, referral codes and text without touching code.
  • Photos are shrunk and stripped of camera and location data on the phone before they upload.
  • Each save starts an automatic build on GitHub Actions that resizes new photos, rebuilds the pages and publishes them a couple of minutes later.

Getting in touch, without a server

  • The contact form, the suggestion box and the chat box all email me through one small Cloudflare Worker.
  • The chat box answers common questions from answers I wrote, with no AI model behind it, so it can't make things up. Anything else it passes to me.
  • Hidden trap fields catch spam bots, so there are no puzzles for people to solve.

Built to be found

  • Every page has its own title and description, structured data that search engines read, and a place in a sitemap with dates and images.
  • Each referral offer gets its own page, generated from one data file, and each service has its own page too.
  • When a page changes, the site tells Bing and other search engines right away, and a plain-text summary is kept up to date for AI tools.

Private by default

There are no tracking cookies and no cookie banner. Visits are counted with a cookieless counter that only shows me totals. The details are on the privacy page.

A few extras

There's a terminal you can open on any page (press ~), with a small game hidden inside, and a 3D logo viewer built with Three.js.
